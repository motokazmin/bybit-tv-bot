# 0002. По умолчанию Bybit Demo Trading, а не testnet

## Контекст
Бота нужно попробовать без риска и без передачи кому-либо ключей от реального счёта.
У Bybit есть testnet (отдельная биржа со своими ценами и ликвидностью) и Demo Trading (виртуальный счёт на основной бирже с реальными ценами, домен `api-demo.bybit.com`).

## Решение
- Режим `mode: demo` используется по умолчанию и подключает pybit с `demo=True`.
- `mode: live` переключает на реальный счёт. Код при этом один и тот же.
- При старте бот делает авторизованный запрос. Если ключ не подходит к выбранному режиму, бот завершается с понятным сообщением.

## Последствия
- Цены и правила инструментов совпадают с реальными, поэтому поведение на демо-счёте показательно.
- Demo Trading поддерживает не все эндпоинты. Используются только поддерживаемые: market, позиции, плечо, ордера, баланс, режим маржи и позиции.
- Demo-ключ нельзя использовать в `live` и наоборот.
