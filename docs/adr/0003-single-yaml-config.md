# 0003. Все настройки в одном config.yaml с defaults и переопределениями по парам

## Контекст
Нужны индивидуальные настройки: плечо, пары, размер позиции.
Веб-панель или Telegram-управление заметно увеличивают объём MVP. Пользователь не обязательно технический.

## Решение
- Один файл `config.yaml`: ключи, secret, режим, блок `defaults` и словарь `symbols` с переопределениями для отдельных пар.
- Валидация через pydantic с `extra="forbid"`: опечатка в имени параметра приводит к понятной ошибке при старте.
- Плечо проверяется против максимума Bybit для пары при старте (`Trader.check_ready`).
- Режим маржи задаётся на весь аккаунт, а не на пару: на Unified-аккаунте Bybit он устанавливается на уровне аккаунта.

## Последствия
- Чтобы применить изменения, бота нужно перезапустить.
- Секреты лежат в том же файле. Файл исключён из git и Docker-образа и монтируется в контейнер только для чтения.
- Telegram или веб-интерфейс можно добавить позже как ещё одну реализацию `SettingsPort`, прикладной код при этом не меняется.
